## How to Run the Notebook

### Google Colab
1. Navigate to [Google Colab](https://colab.research.google.com).
2. Click **File > Upload notebook** and select `24_1755_BSCE-S_W02.ipynb`.
3. Open the **Files** sidebar on the left and upload `site_inspection_log.csv`.
4. Click **Runtime > Restart session and run all** (or press `Ctrl + F9` / `Cmd + F9`).
5. Verify outputs:
   - Cell 3 prints `Hello from CML3112` and `4`.
   - Cell 5 prints `17`.
   - Cell 8 prints `4`.
